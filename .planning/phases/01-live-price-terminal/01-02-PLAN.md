Export an interface `PricePoint` with a numeric `timestamp` and numeric `price`, and an interface `PriceStreamState` with four members: `ticks` typed as `PriceStreamEvent`, `history` as a record from ticker string to an array of `PricePoint`, `tickers` as a string array, and `status` as `ConnectionStatus`. Export `usePriceStream`, taking an optional url defaulting to the string `/api/stream/prices` and returning `PriceStreamState`. Implement it with one `useEffect` whose dependency array holds only the url. Inside, construct a single `EventSource` and keep it in a ref. Wire `onopen` to set status `connected`; `onerror` to set status `reconnecting` when the source's `readyState` is the CONNECTING value and `disconnected` otherwise, because the native `EventSource` retries on its own using the `retry: 1000` directive the server already emits — track state, never hand-roll a backoff loop.
