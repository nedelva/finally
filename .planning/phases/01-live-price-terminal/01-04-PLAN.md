`frontend/components/Sparkline.tsx` — a client component. Export `Sparkline`, taking a required data array of the `PricePoint` type exported by `frontend/lib/usePriceStream.ts`, and optional numeric width and height. Render a Recharts line chart with a single line bound to the price key, using the primary blue theme colour for the stroke, a thin stroke width, dots disabled, and animation disabled — animation would fight a twice-a-second data update and cost frames for no visual gain.

Handle sizing deliberately, because it is what makes this component testable. When both width and height are supplied, render the chart at those explicit dimensions. Otherwise wrap it in Recharts' responsive container inside a fixed-height, fixed-width cell-sized box. This matters because jsdom reports a zero-sized container, so a responsive-only component renders nothing in a test and the coverage would be vacuous; the tests pass explicit dimensions so Recharts actually emits an SVG.

Render no axes, no grid, no tooltip, and no legend — this is an inline glance-value chart in a table cell. Use Recharts rather than hand-drawing a canvas or an SVG polyline: RESEARCH.md's "Don't Hand-Roll" table is explicit that Recharts handles the scaling and resizing, it is already resolved in the dependency tree at 3.10.1, and introducing `lightweight-charts` would mean an unpinned new install for no benefit at ten tickers.

Guard the degenerate inputs explicitly rather than relying on the library: return the empty-but-present cell for a zero-length array so the table's column widths stay stable, and let a single point through to the chart, which draws a dot-free line of zero length. Both cases are real and frequent — every row begins at zero points on page load, passes through exactly one point on its first tick, and PLAN.md's "sparklines fill in progressively" is a description of precisely that ramp.

Do not slice, resample, or re-cap the data here: the hook already caps it at `PRICE_HISTORY_LIMIT`, and a second cap in the view would be a duplicate invariant that could drift.
