<objective>
**As a** FinAlly user, **I want to** see every holding in a live positions table and a portfolio
heatmap sized by weight and coloured by profit or loss, **so that** I can read my concentration and
my winners and losers at a glance instead of doing the arithmetic myself.

Purpose: 03-01 made trading work but a filled position is currently invisible — cash moves and
nothing else does. This plan makes the portfolio itself readable, and it is the first surface where
D-03's avg_cost fallback becomes something the user actually looks at, so it is where the fallback
must be rendered honestly rather than coloured as a gain or a loss.

Output: `PositionsTable.tsx`, `Heatmap.tsx`, both mounted in the terminal layout with the heatmap's
tiles wired into the existing click-to-select selection.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-11 | Tampering | ticker strings rendered as SVG `text` inside Treemap tiles | low | accept | React escapes interpolated text in SVG the same way it does in HTML, no `dangerouslySetInnerHTML` is used, and tickers are already format-validated to 1-5 alphanumeric characters at the Phase 2 API boundary |
| T-03-12 | Tampering | non-finite numbers reaching tile geometry or table cells | medium | mitigate | Every displayed value passes through `format.ts`'s null-safe helpers, and every derived value comes from `deriveLivePosition`, whose `avg_cost > 0` guard prevents a division-by-zero percent |
| T-03-13 | Information Disclosure | a holding silently dropped from the table or heatmap | medium | mitigate | No filter is applied to the positions array in either component; the zero-P&L and off-watchlist cases render through the neutral colour branch rather than being excluded, and the prohibition above states this explicitly |
| T-03-14 | Denial of Service | per-tick re-layout of the treemap | low | accept | Position count is bounded by the watchlist at roughly ten entries and recharts recomputes a squarified layout over that set well inside the ~500ms SSE cadence |
</threat_model>
