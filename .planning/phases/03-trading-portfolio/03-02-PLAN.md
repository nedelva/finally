## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `GET /api/portfolio` response → React state | Server-supplied numbers rendered into the DOM |
| SSE tick stream → `useLiveTotalValue` | Server-pushed prices drive a continuously recomputed displayed figure |

**Package legitimacy:** no package-manager install tasks this plan; no new dependencies.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-08 | Tampering | ticker strings and numeric fields rendered in `Header.tsx` | low | accept | React escapes all interpolated text by default and no `dangerouslySetInnerHTML` is introduced; numeric values pass through `formatMoney`, which coerces non-finite input to an em dash |
| T-03-09 | Information Disclosure | header figures rendered before the portfolio loads | low | mitigate | `formatMoney(null)` renders an em dash rather than a fabricated zero, so no figure is displayed that the server has not actually supplied |
| T-03-10 | Denial of Service | per-tick recomputation of the total across all positions | low | accept | The watchlist is bounded to a handful of tickers and the derivation is a single linear pass over at most ten positions at the existing ~500ms SSE cadence; no memoisation is warranted |
</threat_model>
